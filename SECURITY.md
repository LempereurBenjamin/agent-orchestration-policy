# Security policy

Do not include credentials, OAuth tokens, provider configuration, session content,
or customer/project secrets in issues, commits, or pull requests.

For a suspected vulnerability, use a GitHub private security advisory for this
repository when available. Otherwise, open a private repository issue visible only
to maintainers and include the affected commit, impact, safe reproduction details,
and any mitigation already applied. Do not disclose exploitable details in external
channels before maintainers have assessed the report.

The supported policy bundle is the current default branch and its reviewed release
tags. Maintainers will assess reports, coordinate a fix, and document the release
containing the remediation.
